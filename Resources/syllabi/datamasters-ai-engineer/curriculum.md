# Data Masters — Percorso AI Engineer

Source: https://datamasters.it/catalogo/percorsi-di-carriera/ai-engineer-50/ (section "Cosa imparerai nel percorso AI Engineer?")
Retrieved: 2026-10-19. Hours per module are not stated on the page; FAQ says ~3 months at 3–5 h/week.
A "Scarica la brochure" button exists but exposes no direct PDF URL (likely a lead form) — not downloaded.

1. **Introduzione al Data Driven Mindset** — AI fundamentals (learning types, predictive vs generative, AI workflows & agents, bias/hallucination/privacy), data culture, cloud & AI (IaaS/PaaS/SaaS, BI, blockchain).
2. **Fondamenti di Python** — syntax, control flow, functions, files, list comprehensions; lists/tuples/dicts/sets; encoding & IEEE 754; JSON/Pickle; HTTP & Requests; OOP, dunder methods, exceptions; mini-projects.
3. **GenAI for Developers** — prompt engineering (basic/advanced), Claude Code (CLAUDE.md, subagents, skills, plugins, MCP, hooks), context engineering, harness engineering (agent loop, tools, memory, orchestration), GenAI for data analysis & dev (ChatGPT, Copilot, Cursor, Custom GPT/OpenAPI, Django).
4. **AI Agents** — n8n automation (agents, memory, RAG, MCP); LLM fundamentals (tokenisation, embeddings); OpenAI Agents SDK (tools, handoffs, tracing, guardrails); LangChain/LangGraph (RAG, re-ranking, structured output, agent patterns); agentic metrics (benchmarks, LLM-as-judge); alignment (RLHF, GRPO); DSPy.
5. **Fondamenti di Agentic AI Security** — OWASP GenAI / LLM Top 10 (LLM01–LLM10), MITRE ATLAS, attacks & mitigations.
6. **ML Operations** — Git/GitHub, uv, pytest, containers & registries, GCP & IAM, Cloud Run, GitHub Actions CI/CD, MLflow.
