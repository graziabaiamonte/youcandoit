# IBM DevOps and Software Engineering Professional Certificate (Coursera)

Source: https://www.coursera.org/professional-certificates/devops-and-software-engineering
Retrieved: 2026-10-19. No official syllabus PDF is offered; extract from the web page.
Duration: 15 courses, ~235 h (sum of per-course estimates); page states ~6 months at 10 h/week.

| # | Course | Hours | Topics |
|---|---|---|---|
| 1 | Introduction to DevOps | 9 | DevOps culture, CI/CD, IaC, TDD/BDD, cross-functional teams |
| 2 | Introduction to Cloud Computing | 12 | Service/deployment models, IaaS/PaaS/SaaS, containers, storage, cloud security |
| 3 | Introduction to Agile Development and Scrum | 13 | Agile, Scrum events/artifacts, user stories, backlog, sprint planning, Kanban |
| 4 | Introduction to Software Engineering | 15 | SDLC, architecture & design patterns, Python basics, web dev |
| 5 | Getting Started with Git and GitHub | 11 | Version control, branches, pull requests, open source |
| 6 | Hands-on Intro to Linux Commands and Shell Scripting | 17 | Linux commands, Bash scripting, pipes/filters, networking basics, cron |
| 7 | Python for Data Science, AI & Development | 24 | Python, data structures, OOP, exceptions, Pandas, NumPy, Jupyter, REST APIs, scraping |
| 8 | Developing AI Applications with Python and Flask | 12 | Flask, routing, CRUD, REST, unit testing, PEP 8, packaging, Watson AI libs |
| 9 | Introduction to Containers w/ Docker, Kubernetes & OpenShift | 17 | Docker, Kubernetes architecture, OpenShift, Istio, YAML deployments |
| 10 | Application Development using Microservices and Serverless | 16 | Microservices vs monolith, REST, cURL/Postman, Swagger, serverless (IBM Code Engine) |
| 11 | Introduction to Test and Behavior Driven Development | 21 | TDD, BDD, Gherkin, unit tests, fixtures, mocks, coverage |
| 12 | Continuous Integration and Continuous Delivery (CI/CD) | 15 | Terraform IaC, Jenkins, GitHub Actions, OpenShift Pipelines, Argo CD |
| 13 | Application Security for Developers and DevOps Professionals | 17 | OWASP, secure coding, threat modelling, container scanning, pentest basics |
| 14 | Monitoring and Observability for Development and DevOps | 16 | Golden signals, OpenTelemetry, Prometheus, Grafana, Instana, logs |
| 15 | DevOps Capstone Project | 20 | Sprint planning, microservice build, containers/serverless, tests, CI/CD deploy |
